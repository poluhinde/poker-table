# За столом — помощник для домашнего покера

Один локальный стол для 2–10 игроков, техасский холдем. Карты раздаёт сервер, решения и ставки остаются за живым столом. Windows-ноутбук и телефоны должны находиться в одной сети. Интернет после первоначальной установки зависимостей не нужен.

## Быстрый запуск

1. На ноутбуке нужен Node.js 24 LTS. На этом компьютере он уже установлен.
2. Откройте **Start Poker.cmd**. Держите окно сервера открытым.
3. Панель ведущего откроется автоматически. Добавьте имена участников.
4. Покажите каждому его персональный QR-код или нажмите «Копировать ссылку» и передайте ссылку. Игрок входит автоматически, без ввода кода. Приглашение можно повторно открыть кнопкой «QR» рядом с именем.
5. Нажмите «Раздать карты». Далее — флоп, тёрн, ривер, завершение раздачи.
6. Телефон показывает личные карты только при удержании самих карт (мышью, пальцем или клавишей Space/Enter после фокусировки). Отпускание, уход в фон и потеря соединения скрывают их.

Если ведущий тоже играет, добавьте его в список. Личные карты лучше открыть на отдельном телефоне. Можно использовать отдельную вкладку по адресу сервера без /host; личный вход и вход ведущего сохраняются отдельно.

## Подключение и Windows

Сервер слушает TCP 3000. Адрес localhost работает только на ноутбуке; для телефона используйте адрес в панели ведущего. Если отображается несколько адресов, выберите адрес Wi-Fi/LAN вашей общей сети (не VPN/виртуального адаптера). Сеть должна разрешать связь между клиентами — гостевая сеть с изоляцией не подойдёт.

Если Windows спрашивает о доступе Node.js к сети, разрешите **частные сети**. Если телефон не открывает страницу, файл **Allow Private Network.ps1** создаёт узкое правило: Node.js, TCP 3000, частная сеть, локальная подсеть. Его нужно один раз запустить из PowerShell администратора. Само приложение настройки файрвола не меняет.

Ноутбук не должен уходить в сон. На телефонах приложение открывается в обычном браузере; установки приложения не требуется.

## Восстановление и личные приглашения

- Перезагрузка страницы и краткий обрыв сети сохраняют место и карты: браузер хранит секретный ключ.
- На другом устройстве откройте прежнюю персональную ссылку или отсканируйте QR-код. Карты сохранятся, предыдущий ключ устройства станет недействительным. На том же устройстве повторное открытие ссылки сохраняет текущий ключ.
- Ведущий может повторно показать тот же QR-код и скопировать ссылку кнопкой «QR» рядом с именем, в том числе после перезапуска сервера. Это не отключает игрока. «Заменить доступ» в окне приглашения аннулирует прежние ссылку, QR-код, ручной код и подключение; карты сохраняются.
- При перезапуске сервера состояние восстанавливается из **data/table.json**.
- «Завершить раздачу» очищает карты, но оставляет участников. «Закрыть стол» удаляет участников и аннулирует их коды.
- Ручной ввод кода оставлен запасным способом: новый код доступен в раскрывающемся блоке приглашения при добавлении игрока или замене доступа. Код хранится в виде хеша. Персональная ссылка восстанавливается из сохранённого состояния без хранения исходного ручного кода и работает для уже существовавших игроков.
- Сохранение записывается через временный файл с заменой; при ошибке записи команда откатывается.
- Повреждённый файл не сбрасывается автоматически, чтобы не потерять раздачу незаметно. Сохраните его копию перед восстановлением.

Если адрес ноутбука в сети изменился, заново откройте приглашение и выберите актуальный адрес сети: секрет приглашения останется прежним. На локальном HTTP кнопка копирования использует запасной способ; если браузер запрещает копирование, ссылка выделяется для ручного копирования.

## Приватность

Клиент получает только свои закрытые карты и уже открытые общие карты. Панель ведущего не получает личные руки и будущие карты. Её секретный ключ передаётся при запуске во фрагменте URL и затем убирается из адресной строки.

Персональная ссылка содержит секрет доступа во фрагменте URL и убирается из адресной строки при открытии; в исходный HTTP-запрос страницы и Referer секрет не попадает. Не передавайте приглашение другим игрокам.

Это приложение для доверенной домашней сети: используется HTTP. Владелец ноутбука имеет доступ к файлу состояния и технически может прочитать колоду. Здесь нет защиты от владельца сервера или от перехвата трафика в недоверенной сети. Не выставляйте порт в интернет и не отправляйте файл состояния другим людям.

## Разработка

Стек: Node.js, TypeScript, Fastify, Socket.IO, React, Vite, CSS. QR-код генерируется локально. Внешние шрифты, CDN и сервисы во время игры не используются.

- npm ci — установка зависимостей по lock-файлу.
- npm run build — проверка типов, сборка интерфейса и сервера.
- npm start — запуск без открытия браузера.
- npm run dev — перезапуск серверного TypeScript при изменениях; интерфейс обслуживается из dist, после его правок нужен npm run build.
- npm test — тесты колоды, приватности, доступа, сохранения и сетевого взаимодействия.
- PORT — альтернативный порт сервера; при его смене правило файрвола тоже нужно изменить.

Структура:

- server/game.ts — колода, участники, команды и сохранение.
- server/app.ts — HTTP и Socket.IO, проверка доступа.
- server/index.ts — запуск на Windows.
- src/main.tsx — экраны ведущего и игрока.
- src/style.css — адаптивное оформление, перевороты и раздача.
- shared/types.ts — общие типы протокола.
- tests/ — автоматические проверки.

При изменении исходников пересоберите приложение. Start Poker.cmd не пересобирает уже существующую сборку каждый раз.

## Новая игра и обновление сервера

В панели ведущего **внизу правой панели** находятся две кнопки:

- **Новая игра** — сбросить карты и нумерацию, сохранив игроков, подключения и персональные QR-ссылки. После подтверждения нажмите «Раздать карты»: начнётся раздача №1.
- **Закрыть стол** — удалить также игроков и их приглашения.

Для применения обновлений запускайте **Restart Poker.cmd**. Он проверит, что порт занят именно этим столом, остановит его и запустит обновлённую версию. Раздача восстанавливается из сохранения. Обычный Start Poker.cmd только открывает уже работающую версию.

## Рассадка игроков

Между раздачами ведущий может перетаскивать игроков за значок ⠿ в списке. Стол сразу показывает новый порядок; после отпускания он сохраняется на сервере и обновляется у игроков. На сенсорном экране тяните за тот же значок. Длинный список автоматически прокручивается у краёв. Escape отменяет перетаскивание. С клавиатуры: сфокусируйте значок и нажимайте ↑ / ↓ (Home / End — в начало / конец).

QR-ссылки, имена и подключения принадлежат игрокам и не меняются. Метка дилера остаётся у прежнего игрока, завершение следующей раздачи передаёт её соседу в новом порядке. Во время раздачи менять места нельзя. При изменении стола другим ведущим или потере связи незавершённая перестановка отменяется.

## Блайнды и таймер

Именованные наборы (например, «Быстрый» или «Медленный») хранятся в `data/table.json`, в `blindPresets`. В раскрытом блоке «Уровни» задайте структуру, введите название и нажмите «Сохранить набор». Это не меняет текущую игру. Повторное сохранение под тем же именем обновляет набор; регистр букв не учитывается. «Применить к игре» отдельно сохраняет изменения текущего расписания. Для следующей игры нажмите «Новая игра», выберите набор и подтвердите: он начнётся с первого уровня. Без выбора используются текущие настройки. Наборы сохраняются после закрытия стола и перезапуска сервера.

Компактная строка внутри овала стола показывает малый и большой блайнд, оставшееся время и кнопку запуска/паузы. Настройки и дополнительные кнопки находятся справа под списком игроков и скрыты в режиме «Только стол». На широком экране правая панель прокручивается независимо от стола. Игроки видят тот же таймер на телефонах. Только ведущий может управлять им.

- «Уровни ▾» открывает и закрывает настройки: длительность уровня (1–180 минут) и до 40 пар блайндов. Быстрый выбор: 5, 10, 15, 20 или 30 минут. До начала игры можно изменить всю структуру; во время игры — только будущие уровни, включая их удаление. Сохранение не сбрасывает текущий уровень, паузу и оставшееся время. Новая длительность применяется со следующего уровня. Переключатель «Автоматическое повышение» управляет только переходом уровней; таймер работает в обоих режимах. Режим можно менять без остановки отсчёта.
- Раздача карт автоматически запускает или продолжает таймер с оставшегося времени. Повторная раздача не обнуляет уже идущий отсчёт. «Запустить» и «Пауза» позволяют управлять им вручную. «Предыдущий» и «Следующий» переключают уровень и дают полное время выбранного уровня, сохраняя состояние запуска/паузы. Будущий уровень можно удалить в раскрываемой таблице настроек. Для сброса таймера и стола используйте «Новая игра».
- По истечении времени уровни переключаются автоматически. Блайнды начатой раздачи остаются прежними: новые применяются при следующей раздаче и показываются отдельной строкой.
- По окончании времени в обоих режимах звучит тройной сигнал и появляется окно поверх интерфейса, включая «Только стол». Звук по умолчанию включён на устройстве ведущего и активируется после первого нажатия в приложении; его можно отключить кнопкой «Звук выкл.». Последняя минута выделяется цветом.
- Таймер работает на сервере и сохраняется в `data/table.json`. Обновление или закрытие вкладки не останавливает его. После перезапуска сервер учитывает прошедшее время; при отключённом ноутбуке уведомления не звучат. В автоматическом режиме по окончании времени выбирается следующий уровень, звучит сигнал и появляется окно. Полное время следующего уровня стоит на паузе до новой раздачи карт; кнопка ручного запуска в этом состоянии недоступна. За время ожидания и перезапуска сервера дополнительные уровни не пропускаются. После последнего уровня часы останавливаются. В ручном режиме по окончании времени часы останавливаются на 00:00, блайнды сохраняются. В окне уведомления можно выбрать следующий уровень или повторить таймер с прежними блайндами. Переход с истёкшего уровня запускает полный отсчёт нового уровня. Новая раздача не скрывает непринятое решение об истёкшем уровне.
- «Новая игра» и «Закрыть стол» останавливают таймер на первом уровне, сохраняя расписание. В режиме «Только стол» блок таймера остаётся видимым.

## Фишка дилера

Белая фишка D / DEALER видна рядом с игроком на столе и плавно перемещается при смене дилера. На телефоне показывается имя дилера.

- При «Новой игре» первый дилер выбирается случайно из текущих участников и показывается сразу. На первой раздаче он сохраняет фишку.
- При самом первом запуске пустого стола выбор происходит при первой раздаче, когда состав уже набран.
- При нажатии «Завершить раздачу» фишка переходит к следующему игроку по часовой стрелке в текущей рассадке. Раздача карт, флоп, тёрн и ривер не перемещают фишку.
- Если между раздачами удалить дилера, фишка сразу переходит ближайшему оставшемуся игроку по кругу с пометкой «Следующий дилер». При раздаче он не пропускается. Удаление других игроков просто убирает их из очереди.
- Перестановка сохраняет фишку за выбранным игроком; последующий обход следует новой рассадке. Выбор и очередь сохраняются после перезапуска сервера.

## Ведущий на планшете

Нажмите кнопку «ВЕДУЩИЙ» справа сверху в панели ведущего. Отсканируйте QR-код планшетом или скопируйте ссылку — панель откроется без ручного ввода кода. Оба устройства должны быть в одной сети, а сервер на ноутбуке должен оставаться запущенным. Управление доступно одновременно с ноутбука и планшета.

## Режим «Только стол»

Кнопка «Только стол» рядом с номером раздачи скрывает шапку, список игроков и остальные панели. Общие карты становятся крупнее, а кнопки раздачи находятся сразу под столом. «Полный вид» возвращает обычный интерфейс. Переключение не меняет раздачу и действует только на этом устройстве.

Ссылка ведущего имеет короткий вид `http://АДРЕС:3000/h/ABCDE`: код из 5 символов можно ввести на телевизоре вручную. Регистр букв не важен. Код сохраняется после перезапуска и новой игры.
